## 1. الهوية البصرية وتوزيع الشاشة (Layout Architecture)
- **عنوان الدرس:** البنية العامة لتطبيقات الويب (General Architecture of Web Applications)
- **الكود المرجعي للدرس:** `lesson_3_1`
- **شريط التقدم العلوي:** الوحدة 3 (تطبيقات الويب) > الدرس 1 > نسبة الإنجاز والدرجات.
- **التصميم العام:** طابع هندسي حديث يبرز طبقات البرمجيات بألوان مميزة:
  - الأزرق السماوي: الواجهة الأمامية (Frontend - شاشة العرض والتفاعل).
  - البنفسجي التقني: الواجهة الخلفية (Backend - منطق العمل والمخدم).
  - الأخضر الزمردي: قاعدة البيانات (Database - حفظ السجلات والبيانات).
- **المنطقة التفاعلية المركزية:** محاكي رحلة الطلب عبر الطبقات الثلاث (Three-Tier Request Flow Visualizer).

## 3. محاكي الـ Widget التفاعلي المقترح (The Interactive Widget)
- **اسم الأداة:** `ThreeTierRequestLifecycleVisualizer`
- **الفكرة التقنية:** رسم تخطيطي متحرك يوضح 3 أعمدة تمثل (الواجهة الأمامية 💻 - الواجهة الخلفية ⚙️ - قاعدة البيانات 🗄️).
  - عند ضغط الطالب على زر "محاكاة نشر صورة" أو "محاكاة بحث عن منتج"، تنطلق حزمة بيانات مضيئة تمثل رسالة الطلب:
    1. تنبثق من شاشة المتصفح.
    2. تنتقل عبر سلك الشبكة نحو المخدم (الواجهة الخلفية).
    3. تقوم الواجهة الخلفية بمعالجة الطلب وفحص الصلاحيات، ثم تطلق استعلاماً لقاعدة البيانات.
    4. ترد قاعدة البيانات بالبيانات، وتعود الإشارة للواجهة الخلفية.
    5. ترسل الواجهة الخلفية الرد للواجهة الأمامية.
    6. ترسم الواجهة الأمامية النتيجة فوراً على شاشة المتصفح.
  - **ميزة تفاعلية:** "أين تقع هذه المهمة؟" لعبة سريعة يرمي فيها الطالب مهام مثل "التحقق من كلمة المرور"، "عرض زر الشراء"، "حفظ رقم البطاقة" داخل الطبقة الصحيحة.
