## 3. محاكي الـ Widget التفاعلي المقترح (The Interactive Widget)
- **اسم الأداة:** `HttpProtocolSimulatorAndJsonVisualizer`
- **الفكرة التقنية:** لوحة محاكاة شبكية تفاعلية تسمح للطالب باختيار نوع العملية:
  1. اختيار الأسلوب: `GET` أو `POST`.
  2. اختيار البروتوكول: `http://` غير المشفر أو `https://` المشفر بـ TLS.
  3. إرسال الطلب ومشاهدة الحزمة الرقمية تنتقل بين المتصفح والخادم:
     - إذا اختار الطالب `HTTP` مع بيانات حساسة، يظهر متجسس يقرأ كلمة المرور فوراً!
     - إذا اختار الطالب `HTTPS`، تظهر كبسولة التشفير الخضراء وتمنع المتجسس تماماً.
  4. استعراض استجابة الخادم مع رمز الحالة المقابل:
     - 200 OK (أخضر).
     - 404 Not Found (أصفر).
     - 500 Internal Server Error (أحمر).
  5. تفكيك كود JSON المعروض وتلوين المفاتيح (Keys) باللون الأزرق والقيم (Values) باللون البرتقالي لتعزيز الفهم البصري.
