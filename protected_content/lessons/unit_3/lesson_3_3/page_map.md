## 1. الهوية البصرية وتوزيع الشاشة (Layout Architecture)
- **عنوان الدرس:** أساسيات تقنية الواجهة الأمامية (Frontend Technology Fundamentals)
- **الكود المرجعي للدرس:** `lesson_3_3`
- **شريط التقدم العلوي:** الوحدة 3 (تطبيقات الويب) > الدرس 3 > نسبة الإنجاز والمسار التعليمي ونقاط الإتقان.
- **التصميم العام:** طابع هندسي معماري مستوحى من تشبيه المبنى الوزاري:
  - **البرتقالي الهيكلي (HTML):** عظام وهيكل المبنى والوسوم الدلالية (Structure & Semantic Skeleton).
  - **الأزرق الأنيق (CSS):** الديكور والطلاء والتنسيق وتجاوب الشاشات (Styling & Responsive Layout).
  - **الأصفر الديناميكي (JavaScript):** الكهرباء والمصاعد والتفاعلية الحية وتصفية البيانات (Behavior & Dynamic Interactivity).
  - **الأخضر الزمردي والمحايد:** مكونات أطر العمل (React Components & Framework Ecosystem).
- **المنطقة التفاعلية المركزية:** مختبر ثلاثية الواجهة الأمامية والتصميم المتجاوب ومحاكي قارئ الشاشة (`FrontendTrinityAndResponsiveLab`).

## 3. محاكي الـ Widget التفاعلي المقترح (The Interactive Widget)
- **اسم الأداة:** `FrontendTrinityAndResponsiveLab`
- **الفكرة التقنية:** لوحة محاكاة معمارية تفاعلية تتضمن 3 أوضاع أساسية:
  1. **مبدل الطبقات الثلاثي (The Layer Switcher):**
     - عند تفعيل **HTML فقط:** تظهر صفحة مكتبة ككتب وروابط مجردة بالأبيض والأسود بنصوص قياسية.
     - عند تفعيل **HTML + CSS:** تكتسي الصفحة ألواناً راقية وتخطيطاً شَبكياً (Grid/Flex) وتنسيقاً أنيقاً للخطوط.
     - عند تفعيل **HTML + CSS + JS:** تصبح الصفحة حية؛ يُفعل شريط البحث الفوري (Live Search Filter) وتحديث العدادات دون إعادة تحميل الصفحة.
  2. **محاكي التجاوب والشاشات (Responsive Viewport Simulator):**
     - مقبض سحب تفاعلي مع أزرار سريعة (Desktop 1200px / Tablet 768px / Mobile 375px).
     - يعاين الطالب كيف تتحول القوائم الأفقية إلى قائمة شطيرة (Hamburger Menu) أو تتكدس البطاقات رأسياً في شاشات الجوال.
  3. **محاكي فحص قارئ الشاشة وSEO (Accessibility & Semantic Inspector):**
     - يعرض الصفحة مرتين: الأولى بوسوم دلالية (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`)، والثانية بـ `<div>` عشوائي.
     - يستمع الطالب لمحاكاة صوتية لقارئ الشاشة، ليدرك كيف ينطق القارئ بنية الموقع ويسهل على الكفيف التنقل بين أقسامه.

## 4. مصفوفة نواتج التعلم الوزارية المرتبطة (Target Learning Outcomes)
- [LO-3.3.1]: التمييز القاطع بين أدوار لغة الهيكل (HTML)، ولغة المظهر والتنسيق (CSS)، ولغة السلوك والتفاعل (JavaScript).
- [LO-3.3.2]: فهم دلالات وسوم HTML الدلالية (`<header>`, `<nav>`, `<main>`, `<footer>`) وأثرها الحاسم على إمكانية الوصول (Accessibility) وتحسين محركات البحث (SEO).
- [LO-3.3.3]: استيعاب مبدأ التصميم المتجاوب (Responsive Design) وحل مشكلة تنوع أحجام الشاشات وتطبيق نهج الأولوية للجوال (Mobile-First).
- [LO-3.3.4]: إدراك دور أطر العمل والمكتبات (React, Vue, Next.js) في تسريع التطوير وبناء مكونات قابلة لإعادة الاستخدام (Reusable Components).
- [LO-3.3.5]: حل السؤال المقالي الوزاري المتوقع (6 درجات) حول تكامل التقنيات الثلاث في صفحة المكتبة وحل ورش التفكير الهندسية.
