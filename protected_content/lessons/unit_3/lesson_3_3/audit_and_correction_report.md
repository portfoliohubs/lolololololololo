## 3. تدقيق سؤال الامتحان المقالي الوزاري [6 درجات] (6-Mark Exam Question)
- **نص السؤال الوزاري الرسمي:**
  > *"اشرح كيف تساهم كل من HTML و CSS و JavaScript في صفحة مكتبة تعرض قائمة كتب، وتكون منسقة، وتصفي النتائج أثناء كتابة المستخدم. [6 درجات] راجع: البنية، المظهر، السلوك."*
- **سلم التصحيح والنموذج المعتمد:**
  - **[2 درجات] مساهمة HTML (البنية والهيكل):** بناء الهيكل الأساسي للصفحة، وتوصيف عناصر إدخال البحث، وقائمة عناوين وأغلفة وتصنيفات الكتب، واستخدام الوسوم الدلالية.
  - **[2 درجات] مساهمة CSS (المظهر والتنسيق):** تنسيق الألوان والخطوط وهوامش البطاقات، وضبط شبكة عرض الكتب، وتطبيق التصميم المتجاوب ليلائم الهواتف والحواسيب.
  - **[2 درجات] مساهمة JavaScript (السلوك والتفاعل):** الاستماع الفوري لأحداث كتابة المستخدم في مربع البحث، وتصفية قائمة الكتب ومطابقتها لحظياً، وتحديث جزء الشاشة دون إعادة تحميل كامل الصفحة.
