# 🗺️ خريطة وتوزيع صفحة الدرس 1-1: هرم DIKW والبيانات الضخمة (Big Data)

## 1. الهوية البصرية ونمط الصفحة
- **طبيعة الدرس:** مفاهيمي وتحليلي استراتيجي (Conceptual & Architectural).
- **النمط البصري المقترح:** تدفق عمودي هادئ ذو خلفية Slate عميقة، مع تمييز هرمي متدرج يعكس فكرة الصعود من البيانات الخام (Data) حتى قمة الهرم الحكيم (Wisdom).

---

## 2. التوزيع الهيكلي المتسلسل للصفحة (Page Flow Layout)

```
┌─────────────────────────────────────────────────────────────┐
│ 1. مشغل الفيديو (16:9) مع العلامة المائية المتحركة          │
│    (اسم الطالب + رقم الهاتف) / حالة الانتظار الفاخرة       │
├─────────────────────────────────────────────────────────────┤
│ 2. صندوق "القاعدة الذهبية للدرس" (The Golden Takeaway)      │
│    [البيانات بلا سياق ركام، والمعلومات بلا تطبيق هباء]      │
├─────────────────────────────────────────────────────────────┤
│ 3. هرم المعرفة DIKW بتنسيق تفاعلي بصري متدرج:              │
│    - البيانات (Data): أرقام ورموز خام بلا معنى مستقل.       │
│    - المعلومات (Information): بيانات وضعت في سياق مفيد.     │
│    - المعرفة (Knowledge): فهم كيفية استخدام المعلومات وتطبيقها│
│    - الحكمة (Wisdom): البصيرة الأخلاقية والاستراتيجية للقرار│
├─────────────────────────────────────────────────────────────┤
│ 4. جدول المقارنة الحاسم: الفروق التطبيقية بين مراحل DIKW    │
│    (المستوى | التعريف المبسط | مثال مستشفى | مخرج القرار)  │
├─────────────────────────────────────────────────────────────┤
│ 5. الأداة التفاعلية المدمجة (Interactive Widget):           │
│    [محاكي محول هرم DIKW]: الطالب يضغط على "قراءة حرارة خام" │
│    فيرى كيف تتحول خطوة بخطوة إلى قرار حكيم من الطبيب!       │
├─────────────────────────────────────────────────────────────┤
│ 6. أبعاد البيانات الضخمة (الـ 5Vs of Big Data):             │
│    - الحجم (Volume) - السرعة (Velocity) - التنوع (Variety)   │
│    - الموثوقية (Veracity) - القيمة (Value)                  │
├─────────────────────────────────────────────────────────────┤
│ 7. صندوق سؤال الـ 6 درجات الوزاري المتوقع:                  │
│    - سيناريو تحليلي لمنظومة مرور ذكية وتطبيق الـ 5Vs        │
│    - زر منسدل: عرض نموذج إجابة الكنترول وتوزيع الـ 6 درجات   │
├─────────────────────────────────────────────────────────────┤
│ 8. شريط النوافذ التكميلية السفلي (Action Dock):             │
│    [ 💊 الكبسولة و PDF A4 ]  [ ❓ 100 سؤال ]  [ 🃏 20 كارت ]│
└─────────────────────────────────────────────────────────────┘
```

---

## 3. نقاط التركيز البصري
- إبراز الفارق بين "المعلومة" و"المعرفة" بلون مميز، حيث يقع 70% من الطلاب في الخلط بينهما في الامتحانات.
- تبسيط كل مصطلح باللغة الإنجليزية بترجمة وتعريب مباشر بجواره دون أي تعقيد.
