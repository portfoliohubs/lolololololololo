## 3. تدقيق سؤال الامتحان المقالي الوزاري [6 درجات] (6-Mark Exam Question)
- **نص السؤال الوزاري الرسمي:**
  > *"اشرح كيف تتعاون الطبقات الثلاث لتطبيق الويب عندما ينشر المستخدم صورة على تطبيق تواصل اجتماعي. [6 درجات] أشر إلى: دور الواجهة الأمامية، والواجهة الخلفية، وقاعدة البيانات."*
- **التحقق من سلم التصحيح والنموذج:**
  - **[درجتان] للواجهة الأمامية:** شاشة ونموذج النشر + استقبال الصورة والنص + إرسال الطلب وعرض المنشور على الـ Timeline.
  - **[درجتان] للواجهة الخلفية:** فحص الهوية والصلاحيات والملف + ضغط الصورة وإدارة الإشعارات وتحديد الجمهور وتوجيه البيانات للحفظ.
  - **[درجتان] لقاعدة البيانات:** تخزين بيانات المنشور الوصفية + تخزين ملف الصورة بنظام الملفات/الكائنات وإتاحتها للاسترجاع.
