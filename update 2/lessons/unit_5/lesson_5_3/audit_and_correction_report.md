## 3. مطابقة نصوص وأسئلة كتاب الوزارة الرسمية (Textbook Cross-Verification)

1. **مفهوم الانفتاح الحقيقي مقابل المجانية (ص 120):**
   - مطابقة تامة لقاعدة: «المجانية وحدها أو الإتاحة العامة لا تجعل البيانات مفتوحة؛ فالانفتاح يتطلب ترخيصاً أو شروطاً واضحة تسمح بالوصول وإعادة الاستخدام وإعادة التوزيع».
   - تدقيق الفحص الرباعي الإلزامي: المصدر، الجودة، طريقة الوصول، والترخيص/شروط الاستخدام وملاءمتها لسؤال التحليل.

2. **مزودو البيانات المفتوحة الثلاثة الكبار (ص 121):**
   - **World Bank Open Data:** إحصاءات الاقتصاد والسكان والتعليم والصحة لمختلف دول العالم — الاستخدام الأمثل للمقارنات الدولية عبر السلاسل الزمنية.
   - **UN Data:** إحصاءات دولية تنشرها الأمم المتحدة والوكالات التابعة لها — مواضيع دولية متعددة مع فحص مصدر المؤشر وتعريفه.
   - **Kaggle:** منصة مسابقات تحليل البيانات تتيح مجموعات بيانات للعامة — أبحاث وتطبيقات تعلم الآلة (Machine Learning) مع تقييم مستقل لكل مجموعة.

3. **واجهات برمجة التطبيقات (APIs) ودورة حياة الطلب والاستجابة (ص 122):**
   - تعريف API: مجموعة قواعد تتيح لبرنامج طلب بيانات أو وظائف من برنامج أو خدمة أخرى تلقائياً.
   - مطابقة الشكل 5.3.1: (1) العميل يرسل طلباً إلى نقطة النهاية (Endpoint)، (2) الخادم يعالج ويعيد استجابة (بيانات أو خطأ)، (3) البرنامج يقرأ الاستجابة ويستخدم البيانات أو يتعامل مع الخطأ.
   - صيغة JSON: صيغة نصية شائعة لتمثيل البيانات المهيكلة تعتمد على الاسم/القيمة، مع التنبيه المنهجي بأنها «ليست الصيغة الوحيدة» التي قد تستخدمها الـ APIs.

4. **حدود وسياسات الاستخدام (ص 122 و 126):**
   - ترسيخ قاعدة: «الوصول عبر API لا يلغي شروط الاستخدام أو الترخيص؛ اتبع حدود الطلبات (Rate Limits) وسياسات الحفظ والنشر».
   - التنبيه لمخاطر إرسال طلبات مفرطة في زمن وجيز وتجنب حظر الخدمة (Error 429).

5. **الاستشهاد العلمي والإسناد ونزاهة الموثوقية (ص 123):**
   - مطابقة العناصر الأربعة للاستشهاد: (1) الجهة الناشرة، (2) اسم مجموعة البيانات، (3) الإصدار/تاريخ الوصول أو التحديث، (4) رابط المصدر (URL).
   - توثيق الحقيقة المنهجية الصارمة: «إن مجرد ذكر المصدر وحده لا يثبت موثوقية البيانات! بل يساعد الآخرين على العثور عليها ومراجعة التحليل، وتبقى جودة البيانات ومنهجيتها بحاجة لتقييم مستقل».

6. **تفكيك وحل سؤال الامتحان الوزاري الرسمي (6 درجات) (ص 124):**
   - توزيع الدرجات الثلاثي (2 + 2 + 2 = 6 درجات):
     - (درجتان): حقك القانوني في استخدام البيانات والترخيص (المجانية لا تعني خلو القيود، والترخيص يحدد حدود الاستخدام والطلبات).
     - (درجتان): السماح للآخرين بالتحقق وتكرار التحليل ومراجعة النتائج والشفافية.
     - (درجتان): تقييم جودة البيانات ومفهوم الموثوقية المستقلة (ذكر المصدر لا يعصم البيانات من العيوب).

7. **تمارين وأنشطة كتاب الوزارة الرسمية (ص 122 - 126):**
   - حل نشاط "فكر وتوقف" عن قاعدتي فحص البيانات المفتوحة (ص 122).
   - حل نشاط "فكر وتوقف" عن العميل والخادم في API (ص 123).
   - حل المثال المحلول لصواب وخطأ والمطابقة (ص 123 - 124).
   - حل أسئلة "تدرب" الأربعة واختيار من متعدد (ص 124).
   - حل نشاط "فكر كمهندس: ابحث ثم قرر" لمقارنة الإنترنت في مصر (ص 125).
   - حل تمرين "طبق ما تعلمته" لتطبيق الطقس وطلب JSON (ص 125).
   - حل تمرين ملء الفراغات الخمسة (ص 126).
   - حل أسئلة الاختيار من متعدد الختامية للدرس (ص 126).
