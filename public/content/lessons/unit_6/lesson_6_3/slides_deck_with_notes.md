### 🎴 الشريحة 4: الخريطة الحرارية (Heatmap)
```markdown
+-------------------------------------------------------------------------------+
|                       🗺️ الخريطة الحرارية (Heatmap)                          |
+-------------------------------------------------------------------------------+
| • التعريف: شبكة أو مصفوفة يمثل فيها اللون أو الصبغة حجم قيمة ثالثة            |
|   مقابلة لتوليفات على محورين.                                                 |
|                                                                               |
| • العناصر الأساسية:                                                           |
|   1. محور س ومحور ص (فئات أو فترات زمنية).                                    |
|   2. خلايا الشبكة الملونة بتدرج مستمر.                                        |
|   3. مفتاح الرسم (Legend) الموضح لتدرج الأرقام وقيم الألوان.                  |
|                                                                               |
| • مثال تطبيقي: متوسط درجة الحرارة لكل شهر في عدة مدن مختلفة.                  |
+-------------------------------------------------------------------------------+
```
* **ملاحظات المتحدث (د. مايكل):**
  "الخريطة الحرارية عبقرية لأنها تستغل حساسية العين للألوان لتعطيك بعداً ثالثاً على شاشة مسطحة ثنائية الأبعاد! لكن انتبهوا: يجب أن يكون المقياس اللوني متصلاً وواضحاً، ومفتاح الألوان حاضراً دائماً لترجمة اللون إلى رقم دقيق."

### 🎴 الشريحة 5: مخطط المستطيلات والفسيفساء (Treemap / Mosaic Plot)
```markdown
+-------------------------------------------------------------------------------+
|            🧱 مخطط المستطيلات / الفسيفساء (Treemap / Mosaic Plot)             |
+-------------------------------------------------------------------------------+
| • التعريف: رسم بياني يعرض تكرارات أو نسب توليفات متغيرين فئويين              |
|   باستخدام مساحات المستطيلات.                                                 |
|                                                                               |
| • كيف نقرأه؟                                                                  |
|   - المساحة الأكبر = النسبة أو التكرار الأعلى.                                |
|   - المساحة الأصغر = النسبة أو التكرار الأقل.                                 |
|                                                                               |
| • مثال كتاب الوزارة (ص 143):                                                  |
|   توزيع الطلاب حسب الجنس (ذكور 60%، إناث 40%) وتفضيلهم للمواد الدراسية        |
|   (رياضيات، علوم، لغة عربية، لغة إنجليزية).                                   |
+-------------------------------------------------------------------------------+
```
* **ملاحظات المتحدث (د. مايكل):**
  "عندما يكون لديك متغيران فئويان وتريد أن يقارن المشاهد الحصص والنسب بحدسه البصري، فإن مساحة المستطيل هي الأفضل لأن الدماغ البشري يقدر المساحات والمستطيلات المتجاورة بسرعة فائقة."

### 🎴 الشريحة 6: أزمة التراكب الزائد للنقاط (Overplotting)
```markdown
+-------------------------------------------------------------------------------+
|                 ⚠️ مشكلة التراكب الزائد للنقاط (Overplotting)                 |
+-------------------------------------------------------------------------------+
| • المشكلة: تراكم آلاف النقاط في المخطط المبعثر في كتلة واحدة صلبة مصمتة،       |
|   مما يخفي الكثافة والتمركز الحقيقي للبيانات.                                 |
|                                                                               |
| • الحلول المنهجية المعتمدة:                                                   |
|   1. تطبيق الشفافية (Transparency / Alpha): لجعل المناطق المزدحمة أغمق.       |
|   2. التجميع في خلايا (2D Binning / Hexbins).                                 |
|   3. التحويل إلى خريطة حرارية ثنائية الأبعاد (2D Density Heatmap).            |
+-------------------------------------------------------------------------------+
```
* **ملاحظات المتحدث (د. مايكل):**
  "إذا كان لديك 50 ألف طالب ورسمت لكل طالب نقطة، ستتحول الشاشة إلى لطخة سوداء مصمتة! هل كل النقاط متساوية؟ لا، هناك مناطق فيها 10 آلاف طالب ومناطق فيها 5 طلاب فقط. بالشفافية والخريطة الحرارية نكشف القلب النابض للبيانات."

### 🎴 الشريحة 7: فن سرد قصص البيانات (Data Storytelling)
```markdown
+-------------------------------------------------------------------------------+
|                   📖 الأركان الثلاثة لسرد قصص البيانات                        |
+-------------------------------------------------------------------------------+
|   1. توضيح الرسالة          | • تحديد فكرة واحدة رئيسية وصريحة في جملة واحدة. |
|   (Clarify Message)         | • الإجابة عن سؤال محدد يهم الجمهور.             |
+-----------------------------+-------------------------------------------------+
|   2. اختيار العناصر وتنقيتها| • حذف المشتتات والزخارف غير الضرورية.           |
|   (Select Elements)         | ⚠️ تحذير: لا تحذف بيانات تغير التفسير!          |
+-----------------------------+-------------------------------------------------+
|   3. توفير معلومات داعمة    | • كتابة العنوان الواضح.                         |
|   (Supporting Context)      | • تسمية المحاور والوحدات والمصدر بدقة.          |
+-----------------------------+-------------------------------------------------+
```
* **ملاحظات المتحدث (د. مايكل):**
  "الرسم البياني بدون قصة هو مجرد زخرفة رقمية. سرد القصص بالبيانات يعني أنك تعرف رسالتك بدقة، وتنظف الرسم من أي تشويش، وتضع كل التسميات والمصادر التي تجعل المشاهد يثق في صدق ما يراه."

### 🎴 الشريحة 8: كاشف الرسوم البيانية المضللة (Misleading Charts)
```markdown
+-------------------------------------------------------------------------------+
|                       🚫 أشهر أفخاخ التضليل البصري                            |
+-------------------------------+-----------------------------------------------+
| فخ التضليل                    | كيف يخدع الجمهور؟                             |
+-------------------------------+-----------------------------------------------+
| 1. بتر المحور (Truncated Axis)| البدء من رقم غير الصفر لتضخيم الفروق الصغيرة. |
| 2. تشويه المقياس اللوني       | قفزات لونية حادة توحي بوجود كوارث غير حقيقية. |
| 3. غياب التسميات والوحدات     | حرمان المتلقي من السياق وفتح الباب للتأويل.   |
| 4. اختيار المخطط الخطأ        | إيحاء باستمرارية أو ارتباطات وهمية لا وجود لها.|
+-------------------------------+-----------------------------------------------+
```
* **ملاحظات المتحدث (د. مايكل):**
  "انتبهوا لهذا الفخ الشهير في الأخبار: عندما ترتفع نسبة مبيعات شركة من 50% إلى 51%، يقص المصمم المحور ويبدأ من 49%، فيبدو العمود الثاني أطول بمرتين! هذا تضليل بصري حتى وإن كانت الأرقام في الجدول صحيحة."
