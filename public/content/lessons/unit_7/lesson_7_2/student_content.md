## 1. معمارية الشبكة العصبية الاصطناعية (Neural Network Architecture)

تتكون الشبكة العصبية من **ثلاثة أنواع رئيسية من الطبقات** (كتاب الوزارة ص 155 - 156):

```
┌──────────────────┐       ┌──────────────────────┐       ┌──────────────────┐
│   طبقة الإدخال   │       │   الطبقات المخفية    │       │   طبقة الإخراج   │
│  (Input Layer)   │ ────► │   (Hidden Layers)    │ ────► │  (Output Layer)  │
├──────────────────┤       ├──────────────────────┤       ├──────────────────┤
│ تستقبل البيانات  │       │ تحول وتستخرج السمات  │       │ تنتج التنبؤات    │
│ الخام (بكسلات/أرقام)│    │ المعقدة تدريجياً     │       │ والنتائج النهائية│
└──────────────────┘       └──────────────────────┘       └──────────────────┘
```

1. **طبقة الإدخال (Input Layer):**
   * هي بوابة دخول البيانات للشبكة؛ تمثل القيم المدخلة (مثل قيم درجات اللون للبكسلات في صورة، أو السمات الرقمية لقرض مالي).
2. **الطبقات المخفية (Hidden Layers):**
   * تقع بين طبقتي الإدخال والإخراج؛ وظيفتها تحويل التمثيلات واستخلاص السمات تدريجياً من البسيط إلى المعقد. سُميت "مخفية" لأنها لا تتفاعل مباشرة مع العالم الخارجي أثناء التشغيل.
3. **طبقة الإخراج (Output Layer):**
   * الطبقة الأخيرة التي تنتج قيماً تناسب المهمة المستهدفة (مثل: احتمالية أن تكون الصورة قطة، أو تصنيف رسالة لـ "عادية/مزعجة").

## 2. التشريح الرياضي للخلية العصبية الحسابية (The Artificial Neuron)

كل خلية عصبية (Neuron) داخل الشبكة تقوم بعملية حسابية محددة بدقة عبر **أربع خطوات متسلسلة** (ص 156):

$$ \text{Output} = f\left( \sum_{i=1}^{n} (w_i \cdot x_i) + b \right) $$

```
 المدخلات (x)          الأوزان (w)             الجمع والانحياز (Σ + b)        دالة التنشيط f(z)         المخرج (y)
  [ x₁ ] ─────────── ( w₁ ) ──────────┐
                                      │
  [ x₂ ] ─────────── ( w₂ ) ──────────┼──► [ z = Σ (wᵢ · xᵢ) + b ] ──► [ f(z) Activation ] ──► [ المخرج النهائي ]
                                      │
  [ x₃ ] ─────────── ( w₃ ) ──────────┘
                                      ▲
                                 [ b: الانحياز ]
```

### عناصر معادلة الخلية العصبية:
1. **المدخلات ($x_i$ - Inputs):** القيم القادمة من طبقة الإدخال أو من مخرجات خلايا الطبقة السابقة.
2. **الأوزان ($w_i$ - Weights):** معاملات عددية تحدد **مدى أهمية وتأثير كل مدخل**؛ الوزن الأكبر يعني تأثيراً أقوى في القرار.
3. **الانحياز ($b$ - Bias):** قيمة ثابتة تُضاف للمجموع لتعديل عتبة تنشيط الخلية والسماح للنموذج بالمرونة حتى عندما تكون جميع المدخلات أصفاراً.
4. **المجموع الموزون ($z = \sum w_i x_i + b$):** حاصل ضرب كل مدخل في وزنه المقابل مع إضافة الانحياز.
5. **دالة التنشيط ($f(z)$ - Activation Function):** دالة رياضية غير خطية تُطبق على المجموع الموزون لتحويل المخرج إلى نطاق محدد وتمكين الشبكة من تعلم العلاقات المعقدة غير الخطية.

## 3. دورة تدريب الشبكة العصبية (Training the Neural Network)

التدريب هو **عملية تعديل معلمات الشبكة (الأوزان والانحيازات) تدريجياً لتقليل دالة الخسارة (Loss Function)** على بيانات التدريب (ص 157).

### 🔄 المراحل الثلاث لدورة حياة النموذج:

| المرحلة | ماذا يحدث فيها؟ | جودة التنبؤ والأداء |
| :--- | :--- | :--- |
| **1. قبل التدريب (Before Training)** | تبدأ الأوزان والمعلمات بتهيئة عشوائية (Random Initialization). | تكون التنبؤات ضعيفة وعشوائية لعدم وجود تعلم مسبق. |
| **2. أثناء التدريب (During Training)** | 1. **التمرير الأمامي (Forward Pass):** حساب المخرجات.<br>2. **دالة الخسارة (Loss Function):** قياس الفارق بين المخرج والهدف الحقيقي.<br>3. **الانتشار العكسي (Backpropagation):** حساب التدرجات (Gradients).<br>4. **خوارزمية التحسين (Optimizer):** تعديل الأوزان تدريجياً لتقليل الخسارة. | تتحسن التنبؤات تدريجياً وتنخفض الخسارة مع تكرار دورات التدريب (Epochs). |
| **3. بعد التدريب (After Training)** | تثبيت الأوزان واختبار أداء النموذج على **بيانات اختبار منفصلة ومستقلة** لم تُستخدم في التدريب لقياس **قدرة النموذج على التعميم**. | أداء عالٍ ومستقر، مع ملاحظة أن التدريب **لا يضمن صحة كل تنبؤ بنسبة 100%**. |

> **⚠️ تنبيه منهجي بالغ الأهمية (ص 157):**
> انخفاض دالة الخسارة على بيانات التدريب وحدها **لا يكفي**؛ فقد يصاب النموذج بـ **فرط التخصيص (Overfitting)** حيث يحفظ بيانات التدريب ويفشل في التعميم على البيانات الجديدة. لذلك يجب دائماً التقييم على بيانات اختبار منفصلة!

## 4. ما هو التعلم العميق؟ والتمثيل الهرمي للسمات (Deep Learning & Feature Hierarchy)

### 📌 مفهوم التعلم العميق (Deep Learning) (ص 158):
**التعلم العميق:** هو فرع من تعلم الآلة يستخدم شبكات عصبية **متعددة الطبقات المخفية (Deep Neural Networks)** قادرة على تعلم تمثيلات متتالية ومتدرجة للبيانات من البسيط إلى المجرد تلقائياً.

### 🏛️ البناء الهرمي للسمات (Feature Hierarchy):
في معالجة الصور على سبيل المثال، تتعلم الطبقات المتتالية السمات بشكل تدريجي (ص 158):

```
┌─────────────────────────┐     ┌─────────────────────────┐     ┌─────────────────────────┐
│     الطبقات الضحلة      │     │      الطبقات الوسطى     │     │     الطبقات العميقة     │
│     (Shallow Layers)    │ ──► │     (Middle Layers)     │ ──► │      (Deep Layers)      │
├─────────────────────────┤     ├─────────────────────────┤     ├─────────────────────────┤
│ سمات بسيطة أولية:       │     │ أشكال وأجزاء مركبة:     │     │ بنية الكائن بالكامل:    │
│ • خطوط مستقيمة          │     │ • شكل العين والأنف      │     │ • وجه إنسان كامل        │
│ • حواف الأشكال (Edges)  │     │ • ملامح الأذن والفم     │     │ • هيكل السيارة أو الجسم │
│ • تدرجات الإضاءة واللون │     │ • انحناءات وزوايا       │     │ • مفاهيم بصرية مجردة   │
└─────────────────────────┘     └─────────────────────────┘     └─────────────────────────┘
```

### ⚡ الميزة الثورية للتعلم العميق:
* **في الطرق التقليدية:** كان المبرمجون والمهندسون يضطرون لتصميم واستخراج السمات **يدوياً** (Manual Feature Engineering)، وهو أمر شاق ومحدود.
* **في التعلم العميق:** تتعلم الشبكة استخراج وتمثيل السمات المعقدة **تلقائياً من البيانات الخام مباشرة**.

## 5. عوامل ازدهار التعلم العميق ومجالات تطبيقه (Drivers & Applications)

### 🚀 العوامل الأربعة التي قادت لثورة التعلم العميق (ص 158):
1. **توفر البيانات الضخمة (Big Data):** وفرة ملايين الصور والنصوص ومقاطع الفيديو عبر الإنترنت لتدريب النماذج.
2. **القوة الحوسبية الهائلة ومسرعات العتاد:** ظهور وحدات معالجة الرسوميات (**GPUs**) ووحدات معالجة الموتر (**TPUs**) القادرة على معالجة آلاف العمليات الحسابية المتوازية بسرعة فائقة.
3. **تطور الخوارزميات الرياضية:** تحسين دوال التنشيط وخوارزميات التحسين وتجنب مشاكل تلاشي التدرجات.
4. **تحسن المعماريات البرمجية وأدوات التطوير:** ظهور أطر عمل مفتوحة ومتقدمة سهلت بناء واختبار النماذج العميقة.

### 🌐 أبرز مجالات التطبيق الرائدة (ص 159):
* **التعرف على الصور والرؤية الحاسوبية:** أنظمة التعرف على الوجوه، الدعم التشخيصي للصور الطبية، كشف وتفادي الأجسام في السيارات ذاتية القيادة.
* **التعرف على الصوت ومعالجة الكلام:** تحويل الكلام إلى نص (Speech-to-Text)، التشغيل الصوتي للمساعدات الذكية، الترجمة الصوتية الفورية.
* **معالجة اللغات الطبيعية (NLP):** الترجمة الآلية، تلخيص النصوص الضخمة، أنظمة الإجابة عن الأسئلة، وتوليد المحتوى.

> **💡 تنبيه نقدي (ص 159):**
> تحقيق أداء مذهل في مهمة محددة **لا يعني أبداً امتلاك الذكاء العام أو الفهم البشري الحقيقي**؛ فالنموذج قد يفشل فجأة إذا تغيرت ظروف البيئة أو دخلت عليه مدخلات خارج نطاق بيانات التدريب.

## 6. تفكيك الأنشطة والتطبيقات المنهجية الرسمية

### 🧩 نشاط: فكر كمهندس (صفحة 160)
**السيناريو:** بناء نظام للتعرف على الأرقام المكتوبة بخط اليد (0 إلى 9) في استمارات رسمية.
* **القرار:** تدريب شبكة عصبية عميقة على آلاف الأمثلة المكتوبة بخط اليد هو الخيار الصحيح؛ لأن كتابة قواعد يدوية لكل خط يد مستحيلة عملياً لتنوع الخطوط.
* **الهرمية المستخرجة للرقم:**
  * الطبقات الضحلة: خطوط صغيرة، حواف، وانحناءات أولية.
  * الطبقات الوسطى: حلقات دائرية (مثل دائرة الرقم 8 أو 0) وخطوط مائلة (مثل خط الرقم 7 أو 1).
  * الطبقات العميقة: تمييز الرقم ككل وتركيبته الكاملة.
* **عوامل النجاح:** توفير بيانات متنوعة تمثل خطوط مختلف الفئات العمرية والجنسيات، واستخدام مسرعات GPU، واختبار النموذج على خطوط جديدة تماماً.
* **المخاطر والتحيز:** إذا تم تدريب النظام على خط اليد لبالغين فقط، فسينخفض أداؤه بشكل غير عادل عند فحص خط يد الأطفال أو كبار السن.
